# План реализации обновления `oldParks.json` из API

## Цель

Сделать автоматизированное обновление файла [oldParks.json](/Users/Oleg991/Documents/GitHub/SwiftUI-WorkoutApp/SwiftUI-WorkoutApp/Resources/oldParks.json) через команду `make update_oldparks`:
- запрос к API: `GET /areas?fields=short&page_size=1000&page={N}`
- постраничная загрузка с `page=1`
- остановка на первом успешном пустом JSON-массиве `[]`
- при любой ошибке сервера/формата ответа — немедленное завершение с ошибкой
- все логи и ошибки скрипта на русском языке
- при успешном обновлении `oldParks.json` обновлять `lastParksUpdateDateString` в [ParksManager.swift](/Users/Oleg991/Documents/GitHub/SwiftUI-WorkoutApp/SwiftUI-WorkoutApp/Services/ParksManager.swift:17) в формате `yyyy-MM-dd'T'HH:mm:ss` (строго как в проекте, например `2025-10-25T00:00:00`)

## Область изменений

- Новый скрипт: `scripts/update_oldparks.py`
- Новые автотесты: `scripts/tests/test_update_oldparks.py`
- Makefile: новая цель `update_oldparks` + описание в `help`
- Обновление даты в коде: `SwiftUI-WorkoutApp/Services/ParksManager.swift` (`lastParksUpdateDateString`)
- Документация: обновление инструкции в `README.md` (или отдельный doc в `docs/`)

## Правила проекта, которые учитываем

- После изменений запускать `make format`.
- В Python-коде и в тестах использовать понятные русские сообщения об ошибках.
- Не выполнять частичную замену целевого JSON при падении: запись только после успешного завершения всей загрузки.
