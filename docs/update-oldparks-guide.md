# Обновление справочника площадок

Для обновления локального файла площадок из API используем команду:

```shell
make update_oldparks
```

## Что делает команда

1. Ищет `oldParks.json` по проекту (или использует явный путь, если он будет передан в скрипт вручную).
2. Загружает данные из `GET /areas?fields=short&page_size=1000&page=N` постранично.
3. Останавливается на первом успешном пустом ответе `[]`.
4. Перезаписывает `oldParks.json` только после полной успешной загрузки.
5. Обновляет `lastParksUpdateDateString` в `ParksManager.swift` датой текущего обновления в формате `yyyy-MM-dd'T'00:00:00` (полночь текущего дня).
6. Между страницами делает паузу 2 секунды.
7. При сетевых ошибках автоматически делает до 3 попыток на страницу.

Если сервер вернул ошибку или ответ невалиден, команда завершается с ошибкой и не записывает частичный JSON.

## Проверка скрипта

```shell
make test_update_oldparks
```
