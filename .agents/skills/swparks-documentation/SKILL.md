# Работа с документацией проекта

## Когда применять

- Перед началом работы с функционалом — изучить документацию (`docs/`, `README.md`)
- При изменении или доработке функционала — актуализировать соответствующие документы
- При добавлении новых экранов или функций — обновить `docs/feature-map.md`
- При обнаружении несоответствий между документацией и кодом — исправить документацию сразу

## Правила

- **`docs/feature-map.md`** — карта экранов и функционала: при добавлении/изменении экранов обновляй её
- Значительные изменения основной документации (`README.md`, `docs/feature-map.md`) — только после согласования с владельцем; мелкие актуализации — без согласования
- Документация — краткой и актуальной: устаревшее удалять, без избыточных описаний и повторений
